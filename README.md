### Capital Quiz
## Descripción del funcionamiento y uso de TreeMap en el ejercicio
En el módulo de lógica del quiz, usamos un `TreeMap` para almacenar los países y sus respectivas capitales. Un `TreeMap` es una estructura de datos de Java que nos permite mantener los elementos ordenados según la clave. En nuestro caso, las claves son los nombres de los países.

![image](https://github.com/user-attachments/assets/d7bdd92b-c038-42df-b459-f51f3a359ed5)

El código está ordenado en distintos paquetes para asegurar que sea entendible y fácil de modificar.

![image](https://github.com/user-attachments/assets/693320ae-e497-450a-90f2-23026911301f)
